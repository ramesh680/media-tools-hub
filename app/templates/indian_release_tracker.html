Indian Regional Release Tracker

Movies and TV shows in Hindi, Tamil, Telugu, Malayalam, Kannada, Marathi, Bengali, Gujarati, Punjabi, Odia, Bhojpuri, Assamese and Tulu — released, CBFC-certified and upcoming — with IMDb ID, release status, Studio, Network, director, cast, trailer and the Top 3 YouTube channels (channel URL|Title). Or enrich only your own title list.

Sources, read live on every run

  • Wikipedia: "List of <Language> films of <Year>" + OTT originals lists
  • IMDb Advanced Search: every India-origin movie, TV movie, series and mini-series released in the window, with director, cast, producers, Studio and streaming Network
  • TMDB + OMDb (the hub's API keys): missing IMDb IDs, genres, directors, cast, studios, TV networks and India streaming providers
  • Wikidata: IMDb IDs, Studio, Network for uploaded titles
  • YouTube: trailer link + Top 3 channels (trailer · full movie · songs)
  • CBFC: official website certificates (best effort — the site blocks many servers)
  • Exports: CSV, Excel, Google Sheets — and a BDR ingest template for the Movies table and for the TV Shows table
